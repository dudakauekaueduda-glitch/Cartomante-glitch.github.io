# Fashion_Baay — Loja de Roupas Premium

Site completo em **HTML5 + CSS3 + JavaScript puro**, pronto para colar no **Lovable** ou hospedar em qualquer servidor estático.

## 📁 Estrutura
```
fashion-baay/
├── index.html          → Página principal da loja
├── admin.html           → Painel administrativo
├── css/
│   ├── style.css         → Estilos da loja (design system completo)
│   └── admin.css         → Estilos do painel admin
├── js/
│   ├── products.js       → Banco de dados (produtos, categorias, depoimentos)
│   ├── main.js            → Toda a lógica da loja (carrinho, favoritos, filtros, modais)
│   └── admin.js           → Lógica do painel administrativo
└── README.md
```

## ✨ Recursos incluídos
- Hero animado + banner de promoções rotativo
- 10 categorias, 20 produtos mockados (fotos, preços, cores, tamanhos, estoque, avaliações)
- Busca inteligente instantânea + filtros (categoria, cor, tamanho, preço, promoções)
- Carrinho lateral com cupom, frete, subtotal e total (persistido em `localStorage`)
- Favoritos, Login/Cadastro/Recuperar senha, Minha Conta (pedidos, endereços, favoritos, config)
- Página de produto (quick view) com galeria com zoom, tabela de medidas e avaliações
- Contador regressivo de promoção, carrossel de depoimentos automático, galeria do Instagram
- Botão flutuante do WhatsApp com mensagem automática
- Dark mode / Light mode, Skeleton loading, Scroll Reveal, Parallax, Loading screen
- Painel administrativo: Dashboard, Produtos, Pedidos, Clientes, Cupons, Promoções, Categorias, Estoque, Relatórios
- 100% responsivo (celular, tablet, desktop) e otimizado para SEO

## 🛠️ Como usar no Lovable
1. Extraia o .zip.
2. Cole o conteúdo de `index.html`, `css/style.css` e `js/main.js` / `js/products.js` no projeto do Lovable (ou envie os arquivos direto).
3. Troque o número do WhatsApp em `index.html` (`https://wa.me/55...`) pelo número real da loja.
4. Troque as imagens de exemplo (Unsplash) pelas fotos reais dos produtos.
5. Publique! 🚀
